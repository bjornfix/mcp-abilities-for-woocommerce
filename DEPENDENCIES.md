# Dependencies

MCP Abilities for WooCommerce depends on three runtime systems. Each link goes to the authority for the named dependency.

- [WordPress Abilities API](https://developer.wordpress.org/apis/abilities-api/) requires WordPress 6.9 or newer and registers the WooCommerce operations.
- [PHP 8.0 or newer](https://www.php.net/releases/8.0/en.php) provides the required server runtime.
- [WooCommerce](https://wordpress.org/plugins/woocommerce/) owns the products, orders, customers, reports, settings, and store data controlled by this add-on.

Install and activate WooCommerce before this add-on.
